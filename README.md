## ✏️ 怎么更新房源内容

### 电脑上更新

1. 用浏览器打开本地的 `edit.html`
2. 修改文字 / 房态 / 上传照片
3. 点右上角「生成网页」→ 下载新的 `index.html`
4. 用新文件替换仓库里的 `index.html` 并提交

### 安卓手机上更新

详见网页版说明：**https://seraph717.github.io/shajing403/guide.html**

简要步骤：

1. 手机浏览器打开收藏的 `edit.html` → 改内容
2. 点「生成网页」→ 下载新的 `index.html`
3. 打开 https://github.com/Seraph717/shajing403/upload/main
4. 选刚下载的 `index.html` 上传
5. 提示文件已存在 → 选**覆盖** → 提交
6. 等 1–2 分钟，网站自动更新（链接不变）
